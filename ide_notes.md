# Git в VS Code: заметки

## Что удобно в VS Code

1. **Визуальный diff при коммите.** Перед коммитом видно построчные изменения
   в боковой панели — не нужно бегать в терминал и вызывать `git diff`.

2. **Разрешение merge-конфликтов встроенным редактором.** VS Code подсвечивает
   конфликтующие блоки и даёт кнопки «Accept Current / Incoming / Both» — это
   сильно быстрее ручного редактирования маркеров `<<<<<<<`, `=======`, `>>>>>>>`.

3. **Интерактивный staging по строкам (Stage Selected Ranges).** Можно закоммитить
   только часть изменений в файле, выделив нужные строки, — удобно, когда в одном
   файле смешаны несвязанные правки.

## Что удобнее в терминале

**Интерактивный rebase (`git rebase -i`).** В VS Code его либо нет, либо он
спрятан в расширениях; в терминале открывается редактор со списком коммитов,
где за секунды можно сделать squash, reword, drop. Плюс массовые операции
(`git log --graph --all`, `git reflog`, `git bisect`) в CLI выполняются быстрее
и нагляднее.
